What the console can and cannot prove

Method

This is an evidence viewer, not a control plane. It shows recorded facts, separates claims from attestations, and refuses to turn overlap into a time-saving claim.

Inputs

Three local sources

  • Run JSONL in .auto-orchestrator/runs/ — lifecycle events, opaque agent IDs and native tool spans.
  • Supervisor SQLite in .auto-orchestrator/supervisor.sqlite3 — durable task states, dependencies, scopes, attempts and review attestations.
  • Worktree manifests in .git/auto-orchestrator/worktrees/ — branch, base commit and workspace path.

No external font, script, analytics or network call is used. The server binds to 127.0.0.1 and rejects writes.

Status semantics

Four different truths

Gate verified
A quality-gate event was re-checked against the current verification policy and its check IDs matched. This is evidence about the configured checks, not proof of full correctness.
Self-reported
A terminal record carries a verification flag without gate attestation. It is displayed as a claim, never counted in the verified total.
Open / no terminal
No finish event was recorded. Open agent spans are shown with dashed ends; the console does not pretend the process is still alive.
Failed / rejected
The terminal status is failed or cancelled, or verification evidence was stale, duplicated or incomplete.
Agent office

Desks are evidence, not theatre

A desk exists only for a registered agent definition. Its status comes from explicit bindings, native spans, run terminals and quality-gate evidence. An unbound native session becomes a ghost desk with no invented name or role.

Open spans are shown with a start-observed / stop-missing warning. They are never presented as proof of liveness, and the console renders no simulated terminal.

Arithmetic

Overlap is not saved time

The timeline shows the union of observed native tool spans. Two overlapping spans increase observed overlap; they do not establish that a serial run would have taken longer.

estimated overlap = Σ agent wall time − run wall time

A positive value is a scheduling indicator, qualified by the CLI as not benchmarked human time saved. Only matched serial/orchestrated repeats produce a speedup claim.

Delegation

Advice is advisory

The Router may recommend single or consider-parallel with a cap of 2–3 agents. The console compares that advice with the native starts actually observed.

“Followed” is a routing observation, not proof of independent work, correctness or efficiency.

Cost

No invented cost

The current evidence schema has no token or price field. This console therefore shows zero cost figures. Adding cost later requires an explicit, reviewable input per platform and model; subscription and usage-based plans must not be mixed silently.

The honest product metric remains: verified successful tasks per unit of measured cost, with unknown cost shown as unknown.

Security

Read-only by construction

  • Only GET is accepted; writes return 405.
  • Run IDs are validated; symlinked logs and assets are rejected.
  • Supervisor leases and raw native IDs are never serialized to the browser.
  • Content is local-only; the UI has no external dependencies or telemetry.
Scope

Project-scoped screens read only from /api/projects/<project_id>/state and /api/projects/<project_id>/runs/<run_id>. Switching projects clears the previous run list before new evidence arrives.
